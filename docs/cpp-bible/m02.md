### Narration script

**\[1 · Title\]** Today your program learns to decide. It tests a condition, and then it takes one of two paths.

**\[2 · if and else\]** An if statement tests a condition. If the condition is true, the body runs. If it is false, the body is skipped.

Add an else branch for the false case. Exactly one branch runs. Think of a fork in the road. A sign says which way to walk, and you never take both paths.

**\[3 · Pass or fail\]** \[HL 5\] Marks is seventy-two. \[HL 6\] The if tests whether marks is at least thirty-five. The test sits inside round brackets.

\[HL 7\] The test is true, so this line runs and prints Pass. \[HL 8\] The else branch is skipped. \[HL 9\] It would print Fail, but only for a mark below thirty-five.

**\[4 · Two paths\]** Here is the decision as a tree. The test is at the top. If it is true, we follow the left path and print Pass. If it is false, we follow the right path and print Fail. The program never follows both paths.

**\[5 · Even or odd\]** \[HL 6\] Cin reads a number. \[HL 7\] An even number has remainder zero when we divide by two. \[HL 8\] That branch prints even. \[HL 9\] Seven has remainder one, so the else branch runs. \[HL 10\] The program prints seven is odd.

### Narration script

**\[1 · Title\]** Today we build a menu with switch. It is a neat way to pick one action from many.

**\[2 · switch and case\]** A switch statement compares one value with many case labels. It jumps to the matching case. The break keyword ends that case.

The default case handles all other values. Without break, the program falls through into the next case. Think of a menu board. You say a number, and the kitchen makes that dish.

### Narration script

**\[1 · Title\]** Today we put a loop inside a loop. With it, you can print triangles, grids and tables.

**\[2 · Nested loops and patterns\]** A nested loop is a loop inside another loop. For each round of the outer loop, the inner loop runs from start to finish.

We use the outer loop for rows, and the inner loop for columns. Think of a clock. The minute hand goes all the way round for every small step of the hour hand.

**\[3 · A star triangle\]** \[HL 5\] The outer loop counts the rows, from one to four. \[HL 6\] The inner loop prints one star for each count up to the row number. \[HL 7\] Row one prints one star.

Row two prints two stars. \[HL 9\] After each row, endl moves to the next line. The result is a triangle.

**\[4 · Rows and stars\]** Here is each row. The inner loop runs as many times as the row number. That is one star in row one, and four stars in row four. The line break comes after the inner loop ends.

**\[5 · A number grid\]** \[HL 5\] The outer loop gives the row r. \[HL 6\] The inner loop gives the column c. \[HL 7\] Each cell shows r times c. \[TRACK r=2\] In row two, the cells are two, four and six. \[HL 9\] The line break ends each row.

### Code shown

File 1: triangle.cpp (scene 3)

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int row = 1; row <= 4; row++) {
        for (int star = 1; star <= row; star++) {
            cout << "*";
        }
        cout << endl;
    }
    return 0;
}
```

**Expected output:**

****

### Bug of the Day

**Bug kind:** output · **Bug file:** triangle.cpp

Wrong code (endl is missing after the inner loop):

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int row = 1; row <= 4; row++) {
        for (int star = 1; star <= row; star++) {
            cout << "*";
        }
    }
    cout << endl;
    return 0;
}
```

Program output (it runs, but the answer is wrong):

```text
**********
```

Fixed code (endl is inside the outer loop):

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int row = 1; row <= 4; row++) {
        for (int star = 1; star <= row; star++) {
            cout << "*";
        }
        cout << endl;
    }
    return 0;
}
```

**Fixed output:**

```text
*
**
***
****
```

**Why:** The line break sits after both loops, so all ten stars go on one line. It must run once per row, inside the outer loop.
