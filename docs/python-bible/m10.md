### Code shown

File 1: design.py (scene 3)

```python
from dataclasses import dataclass

@dataclass
class Expense:
    day: str
    category: str
    amount: float
    note: str = ""

expenses = []

def add_expense(day, category, amount, note=""):
    expenses.append(Expense(day, category, amount, note))

add_expense("2025-03-01", "food", 120.5, "lunch")
add_expense("2025-03-02", "travel", 60, "bus pass")
add_expense("2025-03-03", "food", 80)
print(len(expenses))
print(expenses[0])
```

**Expected output:**

```text
3
Expense(day='2025-03-01', category='food', amount=120.5, note='lunch')
```

File 2: totals.py (scene 5)

```python
expenses = [
    ("food", 120.5),
    ("travel", 60.0),

totals = {}
for category, amount in expenses:
    totals[category] = totals.get(category, 0) + amount
for category in sorted(totals):

print(sum(totals.values()))
```

### Bug of the Day

**Bug kind:** output · **Bug file:** rules.py

Wrong code (a negative expense reduces the total):

```python
expenses = []

def add_expense(category, amount):
    expenses.append((category, amount))

add_expense("food", 100)
add_expense("travel", -500)
print(sum(a for _, a in expenses))
```

Python output (it runs, but the answer is wrong):

```text
-400
```

Fixed code (bad amounts are rejected at the door):

```python
expenses = []

def add_expense(category, amount):
    if amount <= 0:
        raise ValueError("amount must be positive")
    expenses.append((category, amount))

add_expense("food", 100)
try:
    add_expense("travel", -500)
except ValueError as e:
    print("rejected:", e)
print(sum(a for _, a in expenses))
```

**Why:** Nothing stopped a negative amount, so the total silently became wrong. Validate input in one place, before it enters your data.

### Code shown

File 1: money.py (scene 3)

```python
from dataclasses import dataclass, asdict
import json
from decimal import Decimal

@dataclass
class Expense:
    day: str
    category: str
    cents: int
    note: str = ""

def to_cents(text):
    value = Decimal(text)
    if value <= 0:
        raise ValueError("amount must be positive")
    return int(value * 100)

def money(cents):
    return f"{cents // 100}.{cents % 100:02d}"

e = Expense("2025-03-01", "food", to_cents("120.50"), "lunch")
print(e)
print(money(e.cents))
print(json.dumps(asdict(e)))
```

**Expected output:**

```text
Expense(day='2025-03-01', category='food', cents=12050, note='lunch')
120.50
{"day": "2025-03-01", "category": "food", "cents": 12050, "note": "lunch"}
```

File 2: store.py (scene 5)

```python
import json
from pathlib import Path

FILE = Path("expenses.json")

def load():
    if not FILE.exists():
        return []
    return json.loads(FILE.read_text())

def save(items):
    FILE.write_text(json.dumps(items))

items = load()
print(len(items))
items.append({"category": "food", "cents": 12050})
save(items)
print(len(load()))
```

**Expected output:**

```text
0
1
```

```python
import io
import unittest
from decimal import Decimal

def to_cents(text):
    value = Decimal(text)
    if value <= 0:
        raise ValueError("amount must be positive")
    return int(value * 100)

def money(cents):
    return f"{cents // 100}.{cents % 100:02d}"

class TestMoney(unittest.TestCase):
    def test_exact(self):
        self.assertEqual(to_cents("0.29"), 29)

    def test_format(self):
        self.assertEqual(money(12050), "120.50")

    def test_rejects_negative(self):
        with self.assertRaises(ValueError):
            to_cents("-5")

suite = unittest.defaultTestLoader.loadTestsFromTestCase(TestMoney)
result = unittest.TextTestRunner(stream=io.StringIO()).run(suite)
print(result.testsRun, result.wasSuccessful())
```

### Bug of the Day

**Bug kind:** output · **Bug file:** weak.py

Wrong code (the test compares the result with itself):

```python
def to_cents(text):
    return int(float(text) * 100)

def test_cents():
    result = to_cents("0.29")
    assert result == to_cents("0.29")

test_cents()
print("test passed")
```

Python output (it runs, but the answer is wrong):

```text
test passed
```

Fixed code (the test compares with the known right answer):

```python
def to_cents(text):
    return int(float(text) * 100)

def test_cents():
    result = to_cents("0.29")
    assert result == 29

try:
    test_cents()
    print("test passed")
except AssertionError:
    print("test failed: caught the bug")
```

**Why:** A test must compare against an independent, known answer. Comparing a result with the same function's result can never fail, so it proves nothing.

### Bug of the Day

**Bug kind:** output · **Bug file:** quiz.py

Wrong code (the list changes while the loop walks it):

```python
nums = [2, 4, 6, 8]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)
print(nums)
```

Python output (it runs, but the answer is wrong):

```text
[4, 8]
```

Fixed code (build a new list instead):

```python
nums = [2, 4, 6, 8]
nums = [n for n in nums if n % 2 != 0]
print(nums)
```

**Why:** Removing items from a list while looping over it shifts the remaining items, so the loop skips some. Build a new list with a comprehension instead.
