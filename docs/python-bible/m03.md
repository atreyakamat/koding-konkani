### Bug of the Day

**Bug kind:** error · **Bug file:** methods.py

Wrong code (we try to change one letter):

```python
name = "goa"
name[0] = "G"
```

```text
Traceback (most recent call last):
  File "methods.py", line 2, in <module>
    name[0] = "G"
    ~~~~^^^

```

Fixed code (make a new string instead):

```python
name = "goa"
name = name.capitalize()
print(name)
```

**Why:** Strings are immutable, so no letter can be changed in place; build a new string and tie the name to it.

### Narration script

**\[1 · Title\]** Every character in a string has an address. Today we learn to pick characters and slices by position.

**\[2 · Positions in a string\]** Every character in a string has a position, called an index. It starts at zero. Think of a row of beach huts, each with a number on the door. The first hut is zero. You pick one with square brackets. Negative numbers count from the end, so minus one is the last character. A slice cuts a piece. Start, colon, stop. It includes the start, and stops before the stop, just like range.

**\[3 · Index and slice\]** \[HL 1\] The word Palolem has seven letters, with positions zero to six. \[HL 2\] Position zero is the first letter, P. \[HL 3\] Minus one is the last letter, m. \[HL 4\] A slice from one to four takes positions one, two and three. That is a, l, o. The four is not included. \[HL 5\] Leaving out the start means, from the beginning. Pal. \[HL 6\] Leaving out the stop means, to the end. O, l, e, m.

**\[4 · Slices make new strings\]** Here is the one name we have. Word is tied to the string Palolem. Indexing and slicing do not change that string. Every slice makes a new string, and prints it, and forgets it, unless we tie a name to it. The original string is untouched. That fits with what we learned in the last episode.

**\[5 · Steps and reverse\]** \[HL 1\] The same word. \[HL 2\] A slice can have a third number, the step. A step of minus one walks backwards. So the word prints reversed, m, e, l, o, l, a, P. \[HL 3\] A step of two takes every second letter, positions zero, two, four, six. P, l, l, m. \[HL 4\] The length is seven. The last valid index is always the length minus one.

**\[6 · Run it\]** Save the file as reverse dot py. In the terminal, type python, space, reverse dot py. Melolap, reversed, then P l l m, then seven.

**\[7 · Recap\]** Let us recap. One: Indexes start at zero. Two: Negative indexes count from the end, with minus one as the last. Three: A slice wordstart:stop stops before the stop. Four: The last valid index is the length minus one. Pause the video, and say these ideas out loud, once, slowly.

**\[8 · an index too far\]** Bug of the Day. Palolem has seven letters, but the last index is six, because we start at zero. We ask for index seven. Python says, index error, string index out of range. The fix is to count from zero. Or use minus one, to always get the last letter, whatever the length.

### Narration script

**\[1 · Title\]** So far every name held one value. Today we meet the list, a name that holds many.

**\[2 · A list holds many values\]** A list holds many values in one name. Square brackets, with commas between the items. Think of a shopping basket. You can add things, look at the first one, and swap one for another. Items have indexes, starting at zero, just like the letters of a string. But there is one big difference. Unlike strings, lists can be changed in place. Append adds a new item at the end.

**\[3 · Making a list\]** \[HL 1\] A list of three beaches, in square brackets. \[HL 2\] Printing it shows the brackets and the commas. \[HL 3\] Index zero is the first item, Baga. \[HL 4\] Len counts the items. Three. \[HL 5\] Append adds a new item at the end. It changes the list itself. \[HL 6\] Print again, and the list now has four beaches.

### Bug of the Day

**Bug kind:** error · **Bug file:** tracker.py

Wrong code (the list has no items):

```python
marks = []
print(sum(marks) / len(marks))
```

Python output (exactly as Python prints it):

```text
Traceback (most recent call last):
  File "tracker.py", line 2, in <module>
    print(sum(marks) / len(marks))
          ~~~~~~~~~~~^~~~~~~~~~~~
ZeroDivisionError: division by zero
```

Fixed code (check the list first):

```python
marks = []
if marks:
    print(sum(marks) / len(marks))
else:
    print("No marks yet")
```

**Why:** An empty list has length zero, and dividing by zero raises an error; test the list before you divide.
