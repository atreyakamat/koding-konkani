### Narration script

**\[1 · Title\]** Today we store many values under one name. An array is a row of boxes, side by side in memory.

**\[2 · Arrays\]** An array holds many values of the same type. You choose the size when you make it, and the size never changes. Each item has an index. The first index is zero.

The items sit side by side in memory. Think of a row of lockers. The row has one name, and each door has its own number.

**\[3 · Five marks\]** \[HL 5\] The number in square brackets is the size. The list in braces gives the starting values. \[HL 6\] Index zero is the first item.

It prints seventy-two. \[HL 7\] Index four is the last item. It prints fifty-eight.

There is no index five. \[HL 8\] We can change one item by its index. \[HL 9\] Now the third item prints seventy.

**\[4 · Boxes side by side\]** Look at the memory. Each box holds one mark. Each box is four bytes wide.

So the addresses grow by four each time. The computer finds any item by a simple sum. It takes the start address and adds the index times four.

**\[5 · Add them up\]** \[HL 6\] The sum starts at zero. \[HL 7\] The loop runs with i from zero up to four. The test says less than five, so five is never used.

\[HL 8\] Each round adds one item to the sum. \[TRACK sum=72\] After round one the sum is seventy-two. \[HL 10\] At the end, the sum is three hundred and sixty-nine.

### Bug of the Day

**Bug kind:** compile · **Bug file:** marks.cpp

Wrong code (four values for three boxes):

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks[3] = {72, 85, 64, 90};
    cout << marks[0] << endl;
    return 0;
}
```

Compiler output (exactly as g++ prints it):

```text
marks.cpp: In function 'int main()':
marks.cpp:5:35: error: too many initializers for 'int [3]'
    5 |     int marks[3] = {72, 85, 64, 90};
      |                                   ^
```

Fixed code (the array has four boxes):

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks[4] = {72, 85, 64, 90};
    cout << marks[0] << endl;
    return 0;
}
```

**Fixed output:**

```text
72
```

**Why:** The size says three boxes, but the list has four values. The compiler stops, because the fourth value has no box.

```cpp
#include <iostream>
using namespace std;

int main() {
    int marks[5] = {72, 85, 64, 90, 58};
    int best = marks[0];
    for (int m : marks) {
        if (m > best) {
            best = m;
        }
    }
    cout << "Best: " << best << endl;
    return 0;
}
```

```text
Warmest: -2
```

### Code shown

File 1: bubble.cpp (scene 3)

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5] = {5, 3, 8, 1, 4};
    int n = 5;
    for (int pass = 0; pass < n - 1; pass++) {
        for (int j = 0; j < n - 1 - pass; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
    for (int x : a) {
        cout << x << " ";
    }
    cout << endl;
    return 0;
}
```

File 2: selection.cpp (scene 5, 6)

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5] = {5, 3, 8, 1, 4};
    int n = 5;
    for (int i = 0; i < n - 1; i++) {
        int m = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[m]) {
                m = j;
            }
        }
        int t = a[i];
        a[i] = a[m];
        a[m] = t;
    }
    for (int x : a) {
        cout << x << " ";
    }
    cout << endl;
    return 0;
}
```

### Bug of the Day

**Bug kind:** output · **Bug file:** bubble.cpp

Wrong code (the swap has no helper box):

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[3] = {3, 1, 2};

        for (int j = 0; j < n - 1 - pass; j++) {

                a[j] = a[j + 1];
                a[j + 1] = a[j];
            }
        }
    }
    for (int x : a) {
        cout << x << " ";
    }
    cout << endl;
    return 0;
}
```

Program output (it runs, but the answer is wrong):

```text
1 1 2
```

Fixed code (a helper box keeps the old value):

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[3] = {3, 1, 2};
    int n = 3;
    for (int pass = 0; pass < n - 1; pass++) {
        for (int j = 0; j < n - 1 - pass; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
    for (int x : a) {
        cout << x << " ";
    }
    cout << endl;
    return 0;
}
```

**Fixed output:**

```text
1 2 3
```

**Why:** The first line overwrites a at j. The second line then copies the new value back, so both boxes hold the same number. A helper box keeps the old value.
