### Bug of the Day

**Bug kind:** error · **Bug file:** parse.py

Wrong code (the text uses slashes, the format uses dashes):

```python
from datetime import datetime

d = datetime.strptime("15/01/2025", "%Y-%m-%d")
```

**Trace trimmed:** last 1 lines

Python output (exactly as Python prints it):

```text
ValueError: time data '15/01/2025' does not match format '%Y-%m-%d'
```

Fixed code (the format matches the text):

```python
from datetime import datetime

d = datetime.strptime("15/01/2025", "%d/%m/%Y")
print(d.date())
```

**Why:** strptime needs a format that matches the text exactly, character for character. A different order or different separators raise a ValueError.

Wrong code (the programmer wanted only 1 and 2):

```python
import random

random.seed(5)
rolls = {random.randint(1, 3) for _ in range(30)}
print(sorted(rolls))
```

Python output (it runs, but the answer is wrong):

```text

```

Fixed code (randrange leaves out the end, like range):

```python
import random

random.seed(5)
rolls = {random.randrange(1, 3) for _ in range(30)}
print(sorted(rolls))
```

**Why:** randint includes both ends, but range, and randrange, stop before the end. Pick the one that matches the numbers you want.

import sys
