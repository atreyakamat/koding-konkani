**\[1 · Title\]** Welcome back! Last time we met names as tags. Today we learn how to make them, how to name them well, and how to change what they point at.

**\[2 · Variables and names\]** A variable is a name tied to a value. You write the name, an equals sign, and the value. Think of a beach shack. The signboard is the name, and the shack is the value. The sign can be moved to a different shack later. The rules are simple. Use letters, digits and underscores. Never start with a digit, and never use spaces. **\[3 · Making names\]** \[HL 1\] A name called beach, tied to the text Calangute. \[HL 2\] A name called visitors, tied to one hundred twenty. \[HL 3\] Now we reuse the name. Python reads visitors, adds thirty, and ties the name to the new answer, one hundred fifty. The old value is simply left behind. \[HL 4\] Print both names. Python shows Calangute, then one hundred fifty.

**\[4 · Names tied to objects\]** Here is what Python holds after the code runs. The name beach is tied to the text Calangute. The name visitors is tied to the number one hundred fifty. The old value, one hundred twenty, has no name on it any more. Python tidies it away. Remember the picture: names are tags, and the objects are the things they point at.

**\[5 · Swap two names\]** \[HL 1\] \[TRACK left=fish\] Left points at fish. \[HL 2\] \[TRACK right=curry\] Right points at curry. \[HL 3\] Now the swap. ### Bug of the Day

**Bug kind:** error · **Bug file:** beach.py

Wrong code (print comes before the assignment):

```python
print(total)
total = 10
```

Python output (exactly as Python prints it):

```text
Traceback (most recent call last):
  File "beach.py", line 1, in <module>
    print(total)
          ^^^^^
NameError: name 'total' is not defined
```

Fixed code (assign first, then use):

```python
total = 10
print(total)
```

**Why:** Python runs lines from top to bottom, so a name must be tied to a value before any line reads it.

### Bug of the Day

**Bug kind:** error · **Bug file:** convert.py

Wrong code (the text is not a number):

```python
count = int("abc")
```

Python output (exactly as Python prints it):

```text
Traceback (most recent call last):
  File "convert.py", line 1, in <module>
    count = int("abc")
ValueError: invalid literal for int() with base 10: 'abc'
```

Fixed code (the text holds digits):

```python
count = int("42")
```

**Why:** int() can only convert text that looks like a whole number, so a word raises a ValueError.
