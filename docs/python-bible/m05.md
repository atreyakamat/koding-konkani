### Narration script

**\[1 · Title\]** Until now every program was one long script. Today we learn to name a block of code, and reuse it.

**\[2 · Your own tools\]** A function is a named block of code. You write it once with def, a name, brackets and a colon. The body is indented below. Nothing runs until you call it, by writing its name with brackets. Think of a recipe card. You write the steps once, then cook the dish whenever you like by naming the card. Functions stop you repeating yourself, and they give your code names that explain what it does.

**\[3 · Define and call\]** \[HL 1\] The word def, a name, empty brackets, and a colon. This line only makes the function. It does not run it. \[HL 2\] The body is indented. This is what runs on every call. \[HL 3\] A call. The name, with brackets. Python jumps up to the body, runs it, and comes back. \[HL 4\] A second call. The same body runs again. Write once, use many times.

**\[4 · What a call does\]** Here is the journey of a call. Python reaches the call line. It jumps up to the def, and runs the body, line by line. When the body ends, Python returns to the line just after the call, and carries on. Defining a function does nothing by itself. Only a call sends Python on this trip.

**\[5 · A function that calls another\]** \[HL 1\] A small function that prints ten dashes. \[HL 2\] Its body. \[HL 3\] A second function, called title. \[HL 4\] Inside it, we call line. \[HL 5\] Print the word. \[HL 6\] And call line again. \[HL 7\] One call to title runs the whole banner. Small functions that do one job, combined, make big programs easy to read.

**\[6 · Run it\]** Save the file as banner dot py. In the terminal, type python, space, banner dot py. A line of dashes, the word KONKANI, and another line of dashes.

**\[7 · Recap\]** Let us recap. One: def makes a function, and the body is indented below it. Two: Nothing runs until the function is called with brackets. Three: A function can call other functions. Four: Write it once, call it as often as you like. Pause the video, and say these ideas out loud, once, slowly.

**\[8 · defined but never called\]** Bug of the Day. We define the function hello, and run the program. Nothing happens. No error, and no output. A def only makes the function. It does not run it. Add a call, the name with brackets, and Hi appears. If a function seems to do nothing, check that you actually call it.

### Narration script

**\[1 · Title\]** A function becomes truly useful when it takes values in, and hands a result back. Today we learn both.

**\[2 · Values in, values out\]** Parameters are names in the brackets of the def line. They receive the values you pass when you call. Return sends a value back to the caller, so you can save it or use it. Think of a fish weighing machine. You put the fish in, and a number comes out that you can write down. Print only shows a value on the screen. Return hands the value over to your program.

**\[3 · Parameter and return\]** \[HL 1\] One parameter, n. It is a name for whatever value we pass in. \[HL 2\] Return sends n times two back. \[HL 3\] We call double with four. Four is tied to n, the body runs, and the answer eight comes back. We tie it to answer. \[HL 4\] Print the answer, eight. \[HL 5\] We can use a call straight inside print. Ten doubled is twenty.

**\[4 · The returned value gets a name\]** Here is the picture. The name answer is tied to the int eight. That int was made inside the function, and returned. The parameter n is gone now, because it only lived while the function ran. Only the returned value survived, and only because we tied a name to it.

**\[5 · Two parameters\]** \[HL 1\] Two parameters, separated by a comma. Values are matched by position. \[HL 2\] Return the product. \[HL 3\] Three and four give twelve. \[HL 4\] A function call is a value, so we can add two calls together. Two times five is ten, and one times one is one. \[HL 5\] Eleven. Since return gives the value back, we can use it anywhere a value fits.

**\[6 · Run it\]** Save the file as area dot py. In the terminal, type python, space, area dot py. Twelve, then eleven.

**\[7 · Recap\]** Let us recap. One: Parameters are names in the def line that receive the passed values. Two: Arguments are matched to parameters by position. Three: return sends a value back to the caller. Four: print shows a value but does not give it back. Pause the video, and say these ideas out loud, once, slowly.

**\[8 · print instead of return\]** Bug of the Day. Our function prints eight, which looks right. But the result we saved prints None. The function used print, not return. Print shows the value on the screen, and the function hands back nothing, which Python calls None. Use return, and the value travels back to the caller.

### Narration script

**\[1 · Title\]** Some inputs are almost always the same. Today we give parameters default values, and name arguments in calls.

**\[2 · Optional and named\]** A default value goes in the def line. Greeting equals Hello. If the caller leaves that argument out, the default is used. Think of a tea stall. Tea comes with sugar by default, unless you say, no sugar. You can also pass arguments by name. Greeting equals Hi. Then the order does not matter, and the call explains itself. Be careful with one thing. Never use a list as a default.

**\[3 · Defaults and keywords\]** \[HL 1\] Two parameters. The second has a default, Hello. \[HL 2\] Join the greeting and the name. \[HL 3\] Only the name is passed, so the default greeting is used. Hello, Asha. \[HL 4\] Two values by position. Namaste replaces the default. \[HL 5\] Keyword arguments. We name each one, so the order does not matter. Hi, Maya.

**\[4 · Which value wins?\]** Here is the rule. If the caller gives a value, that value wins. If not, the default is used. Parameters with defaults must come after the ones without. In the call, positional arguments come first, then keyword ones. Keyword arguments make long calls much easier to read, because every value carries its own label.

**\[5 · Default exponent\]** \[HL 1\] Exp defaults to two. \[HL 2\] Return base to the power exp. \[HL 3\] One value, so exp is two. Five squared is twenty five. \[HL 4\] Two values. Two to the power ten is one thousand twenty four. \[HL 5\] By keyword, in any order. Two cubed is eight.

**\[6 · Run it\]** Save the file as power dot py. In the terminal, type python, space, power dot py. Twenty five, then one thousand twenty four, then eight.

**\[7 · Recap\]** Let us recap. One: name=value in the def line sets a default. Two: Callers can omit an argument that has a default. Three: Keyword arguments carry their own labels. Four: Never use a list or dictionary as a default value. Pause the video, and say these ideas out loud, once, slowly.

**\[8 · a list as a default\]** Bug of the Day. We add fish, then rice, to two separate baskets. But the second basket also holds fish. The default list was made only once, when the def ran. Every call shares it. Use None as the default instead. Inside, if basket is None, make a brand new list, and each call gets its own.

### Narration script

**\[1 · Title\]** Today we meet one of the most beautiful ideas in programming, a function that calls itself.

**\[2 · A function that calls itself\]** Recursion means a function calls itself, on a smaller version of the problem. Think of Russian dolls. Open one and you find a smaller doll, until you reach the smallest, which does not open. That smallest doll is the base case. It stops the calls. Without a base case, the function calls itself forever, until Python stops it with an error. Every call waits for the smaller call it started.

**\[3 · Factorial\]** \[HL 1\] A function that takes n. \[HL 2\] The base case. If n is one, \[HL 3\] the answer is one, and no more calls are made. \[HL 4\] The recursive case. Five times factorial of four. Python must first find factorial of four, which needs factorial of three, and so on, down to one. \[HL 5\] Call it with five. Then the answers come back up. One, two, six, twenty four, one hundred twenty. Five factorial is one hundred twenty.

**\[4 · The call stack\]** Here is the stack. Factorial of five calls factorial of four, and waits. That calls factorial of three, and waits. Down to factorial of one, which answers at once, with one. Now the waiting calls finish, one by one, from the top down. Two, six, twenty four, one hundred twenty. Each call keeps its own n.

**\[5 · A countdown\]** \[HL 1\] A function that takes n. \[HL 2\] The base case. At zero, \[HL 3\] print Liftoff, \[HL 4\] and return. \[HL 5\] Otherwise, print n. \[HL 6\] And call countdown again with one less. Three, two, one, Liftoff. Each call makes the problem smaller, and the base case guarantees that it ends.

**\[7 · Recap\]** Let us recap. One: A recursive function calls itself on a smaller problem. Two: A base case stops the recursion. Three: Each call has its own copy of the parameters. **\[8 · a missing base case\]** Bug of the Day. Our countdown has no base case. It prints three, two, one, zero, minus one, and keeps going. **\[1 · Title\]** In Python, a function is a value, like a number or a string. Today we use that idea.
