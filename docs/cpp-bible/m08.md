### Narration script

**\[1 · Title\]** Today we write code that works for any type. With one template, you replace many copies of the same function.

**\[2 · Function templates\]** A function template is a recipe. You write it once with a placeholder type, usually called T. When you call it, the compiler writes a real function for the type you used.

This is called instantiation. Think of a cookie cutter. One shape works with any dough.

Imagine that you need a biggest function for ints, for doubles and for strings. Without templates, you copy the code three times. With a template, you write it once.

The template itself makes no code. Only when you call it, the compiler writes a real function. If you never call it, no code appears.

**\[3 · One function, many types\]** \[HL 4\] This line says that T is a placeholder for a type. \[HL 5\] The function takes two values of type T, and returns a T. \[HL 6\] It returns the bigger one. \[HL 10\] The compiler sees two ints.

It makes a version with T equal to int. \[HL 11\] Then it sees two doubles, and makes a second version. The output is eight, and two point five. \[HL 4\] The word template and the angle brackets start the recipe.

T is a placeholder for a type. \[HL 5\] T appears as the return type and as both parameter types. \[HL 6\] The question mark line picks the bigger of the two. \[HL 10\] With ints, the compiler makes a version where T is int.

\[HL 11\] With doubles, it makes another version.

**\[4 · From template to real functions\]** Follow the steps. The template is the recipe. A call gives the types of the arguments.

The compiler deduces T. Then it writes a real function, made for that type. Notice that two real functions exist after the build.

One works with ints, and one works with doubles. The compiler wrote both from the same recipe. You write less, and the result is as fast.

**\[5 · Name the type yourself\]** \[HL 10\] We can name the type in angle brackets. Here T is double, so the three is converted to a double. The answer is four point five. \[HL 11\] Here T is string.

Strings compare in alphabetical order. Pear comes after apple, so pear is bigger. \[HL 10\] The angle brackets after the name tell the compiler what T is. The int three is then converted to a double.

\[HL 11\] With strings, the greater one is the one that comes later in the alphabet. Pear comes after apple.

**\[6 · Run it\]** Save the file as explicit dot cpp. Compile it with g plus plus. Then run the program. The program prints four point five, and then pear. Notice that the first answer is four point five, and the second is pear.

**\[7 · Recap\]** Let us recap.

One. A template is a recipe for functions. Two. T is a placeholder for a type.

Three. The compiler deduces T from the arguments. Four. You can name the type in angle brackets.

### Bug of the Day

**Bug kind:** compile · **Bug file:** biggest.cpp

Wrong code (one argument is an int and one is a double):

```cpp
#include <iostream>
using namespace std;

template <typename T>
T biggest(T a, T b) {
    return a > b ? a : b;
}

int main() {
    cout << biggest(3, 4.5) << endl;
    return 0;
}
```

Compiler output (exactly as g++ prints it):

```text
biggest.cpp: In function 'int main()':
biggest.cpp:10:20: error: no matching function for call to 'biggest(int, double)'
   10 |     cout << biggest(3, 4.5) << endl;
      |             ~~~~~~~^~~~~~~~
biggest.cpp:5:3: note: candidate: 'template<class T> T biggest(T, T)'
    5 | T biggest(T a, T b) {
```

Fixed code (the type is named):

```cpp
#include <iostream>
using namespace std;

template <typename T>
T biggest(T a, T b) {
    return a > b ? a : b;
}

int main() {
    cout << biggest<double>(3, 4.5) << endl;
    return 0;
}
```

**Fixed output:**

```text
4.5
```

**Why:** The compiler must find one T for both arguments. An int and a double give two different types, so deduction fails. Name the type yourself.

**\[1 · Title\]** Today we build a container. With a class template, the same class can hold ints, doubles or strings.

**\[2 · Class templates\]** A class template puts a type placeholder on the whole class. When you make an object, you name the type in angle brackets. The compiler then builds a class for that type.

The standard library containers, such as vector, are class templates. Think of a storage box with a blank label. You write int, double or string on it when you use it.

A class template works like a function template, but for a whole class. You write the class once, and it holds any type.

This is how vector, map and unique pointer are written. You are about to build a small one yourself.

**\[3 · A Box template\]** \[HL 5\] T is the placeholder. \[HL 7\] The member has type T. \[HL 10\] The constructor takes a T. \[HL 11\] The getter returns a T.

**\[4 · One template, two classes\]** Each use of the template with a new type makes a new class. Box of int holds an int. Box of string holds a string. They do not share anything, except the recipe.

Notice that Box of int and Box of string are two different types. They share a recipe, but they are not the same class. You cannot put one into the other.

```cpp
#include <iostream>
#include <vector>
using namespace std;

template <typename T>
class Stack {
    vector<T> items_;

public:
    void push(const T& x) { items_.push_back(x); }
    T pop() {
        T x = items_.back();
        items_.pop_back();
        return x;
    }
    bool empty() const { return items_.empty(); }
};

int main() {
    Stack<int> s;
    s.push(1);
    s.push(2);
    s.push(3);
    while (!s.empty()) {
        cout << s.pop() << " ";
    }
    cout << endl;
    return 0;
}
```

**Expected output:**

```text
3 2 1
```

```cpp
#include <iostream>
```

```text
3
```
