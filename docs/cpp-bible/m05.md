### Narration script

**\[1 · Title\]** Today we look under the hood. Every variable lives at an address in memory. Soon you will use that address.

**\[2 · Memory and addresses\]** Memory is a long row of bytes. Each byte has a number, called its address. A variable lives at one address, and it fills as many bytes as its type needs.

The ampersand in front of a variable gives its address. Think of a street of houses. Each house has a number, and a family lives inside.

**\[3 · The gap between boxes\]** \[HL 5\] An array of three ints. \[HL 6\] The ampersand gives the address of the first item. We view it as a char address, so that we can count bytes. \[HL 7\] This is the address of the second item.

\[HL 8\] The difference is four bytes. That is the size of one int. The real addresses change from run to run, but the gap is always four.

**\[4 · Addresses in a row\]** Look at the three boxes. The first sits at address one thousand. The next sits at one thousand and four.

The last at one thousand and eight. These addresses are examples. On a real computer, the numbers differ every time you run the program.

**\[5 · Sizes decide the gap\]** \[HL 5\] A char takes one byte. \[HL 6\] An int takes four. \[HL 7\] A double takes eight.

\[HL 8\] An address itself takes eight bytes on a sixty-four-bit computer. Remember this. We will store addresses in variables soon.

### Bug of the Day

**Bug kind:** compile · **Bug file:** addr.cpp

Wrong code (an address goes into a plain int):

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;
    int where = &fish;
    cout << where << endl;
    return 0;
}
```

Compiler output (exactly as g++ prints it):

```text
addr.cpp: In function 'int main()':
addr.cpp:6:17: error: invalid conversion from 'int*' to 'int' [-fpermissive]
    6 |     int where = &fish;
      |                 ^~~~~
      |                 |
      |                 int*
```

Fixed code (a pointer type holds the address):

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;
    int* where = &fish;
    cout << (where != nullptr) << endl;
    return 0;
}
```

**Fixed output:**

```text
1
```

**Why:** An address has its own type. For an int, the type is int star. A plain int cannot hold it.

### Bug of the Day

**Bug kind:** compile · **Bug file:** pointer.cpp

Wrong code (an int pointer holds the address of a double):

```cpp
#include <iostream>
using namespace std;

int main() {
    double price = 1.5;
    int* p = &price;
    cout << *p << endl;
    return 0;
}
```

Compiler output (exactly as g++ prints it):

```text
pointer.cpp: In function 'int main()':
pointer.cpp:6:14: error: cannot convert 'double*' to 'int*' in initialization
    6 |     int* p = &price;
      |              ^~~~~~
      |              |
      |              double*
```

Fixed code (the pointer type matches):

```cpp
#include <iostream>
using namespace std;

int main() {
    double price = 1.5;
    double* p = &price;
    cout << *p << endl;
    return 0;
}
```

**Fixed output:**

```text
1.5
```

**Why:** The type of a pointer says how to read the bytes at the address. A pointer to int cannot point at a double.

### Bug of the Day

**Bug kind:** compile · **Bug file:** shared.cpp

Wrong code (a raw new result is assigned with an equals sign):

```cpp
#include <iostream>
#include <memory>
using namespace std;

int main() {
    shared_ptr<int> a = new int(5);
    cout << *a << endl;
    return 0;
}
```

Compiler output (exactly as g++ prints it):

```text
shared.cpp: In function 'int main()':
shared.cpp:6:25: error: conversion from 'int*' to non-scalar type 'std::shared_ptr<int>' requested
    6 |     shared_ptr<int> a = new int(5);
      |                         ^~~~~~~~~~
```

Fixed code (make_shared builds the object):

```cpp
#include <iostream>
#include <memory>
using namespace std;

int main() {
    shared_ptr<int> a = make_shared<int>(5);
    cout << *a << endl;
    return 0;
}
```

**Fixed output:**

```text
5
```

**Why:** The shared pointer constructor from a raw pointer is explicit, so an equals sign does not work. Make shared is also faster and safer.
